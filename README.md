# ダンジョンメーカー

プレイヤーがダンジョン側の、薄いブラウザフォロワー（v0）。宝を置いて侵入を迎え、落とし物で巣穴を整える。道中イベントやノードマップはない。

MIT ライセンス（既存の `LICENSE` を維持）。

## 配信形態（固定）

**通常のブラウザで開く単ページ Web アプリ** だけ。状態の薄い永続化は `localStorage`。

入れない: Capacitor / Electron / React Native / Flutter / Tauri / その他のネイティブ・モバイル殻。

## ローカル起動

[pnpm](https://pnpm.io/) を使う。

```bash
pnpm install
pnpm dev
```

ブラウザで表示された URL（既定は http://localhost:5173 ）を開く。

静的ビルド:

```bash
pnpm build
pnpm preview
```

Vercel は Vite の静的出力（`dist`）をそのまま載せられる。

ロジック確認:

```bash
pnpm test
```

## v0 の遊び方

1. ラン開始は **1×1 コア**。出せる宝は **銅貨袋** だけ。
2. コアをクリックして宝を置き、**誘引する**。盗賊が宝目当ての進路を自動で歩く。
3. 第1波を守り切ると落とし物が1つ。**巣穴を拡張する**か **削り罠を置く**。
4. 宝を置き直してもう一度誘引する。拡張も罠もなしだと第2波に奪われやすい。
5. 失敗・クリア後は **最初から** で即リトライ。周回回数だけ `localStorage` に残る。
